topic: System-wide text translation overlay (Grammarly-like)
updated: 2026-11-01T13:43
---

- (decision) Platform: macOS first (Flet), designed for cross-platform extension later.
- (decision) Scope: system-wide (works in any app), Grammarly-like always-on feel.
- (decision) Launch: manual via global hotkey (must not conflict with existing shortcuts); auto-trigger not primary.
- (decision) Guardrails: skip password/secure fields, empty/very long selections.
- (decision) Placement: outside selection when possible; else layer directly over selection (Google Images style, no card/tooltip/pill).
- (decision) Dismissal: click outside, Escape, new selection, or focus change; keep result visible after translation; no auto-dismiss/nagging.
- (decision) Flow: confirmation-first 'Translate this?' with language picker; remember last pair; easy to change; source auto-detected.
- (decision) Post-translate: toggle overlay visibility to flip between original and translated.
- (decision) Output: copy to clipboard only for v1 (no auto-replace/insert).
- (decision) Language picker: dropdown with recent selections at top, rest below, type-to-filter/search box inside dropdown.
- (decision) Backend: same Ollama + whisper-server stack/deps, reasoning disabled; only frontend changes.
- (decision) Accessibility: menu bar/system tray app recommended for macOS v1 to manage permissions/prefs/hotkeys cross-platform later.
- (decision) Stakes: personal utility now, prototype to ship after testing.
- (event) spines finalized
